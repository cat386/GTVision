# GTVision

Графический backend использует Material 3 с тёмной темой Gruvbox по умолчанию. Быстрый запуск
формы с полями, списком, флажками, переключателями и диалогом подтверждения

```sh
cargo run --example material
```

В графический кадр передаётся сцена с геометрией, состояниями и clipping.
Кнопки, поля, списки, переключатели, окна, меню, полосы прокрутки и прогресса
рисуются графическими примитивами. Подписи используют встроенный Roboto.
Редакторы, таблицы, деревья и пользовательские символьные представления
пока передают содержимое через ячейки. Их координаты layout остаются
логическими единицами, преобразуемыми в пиксели.

Токены цветов определены в `src/material.rs`, отрисовка — в
`src/material_render.rs`. Лицензия Roboto находится в `assets/OFL-Roboto.txt`.

## Заголовки окон и диалогов

Заголовок выделен отдельной полосой. Справа находятся кнопки сворачивания,
распахивания/восстановления и закрытия. Сворачивание оставляет на рабочем
столе заголовок окна. Нажатие на его свободную область или на кнопку
восстановления возвращает содержимое. Размеры дочерних элементов и данные
полей сохраняются.

В заголовок можно добавить любой `View` через `Window::add_header` или
`Dialog::add_header`. Виджеты имеют высоту в одну логическую строку и
координаты относительно `header_bounds()`. Текст заголовка ограничивается
слева от первого виджета, а область оконных кнопок зарезервирована.

```rust,no_run
use gtvision::*;

let mut window = Window::new(Rect::new(2, 2, 82, 24), "Документы", 1);
let width = window.header_bounds().width();
let mut action = Button::new(Rect::new(width - 12, 0, width - 1, 1), "Обновить", 200, bf::NORMAL);
action.vs.grow_mode = gf::GROW_LO_X | gf::GROW_HI_X;
window.add_header(action);
```

`header_mut()` даёт доступ к группе заголовка, её виджетам и раскладке.
Tab и Shift+Tab переходят между виджетами заголовка и содержимым окна.
Оконные кнопки управляются флагами `wf::CLOSE`, `wf::ZOOM`, `wf::MINIMIZE`.
Программное управление доступно через `minimize()`, `restore()`,
`is_minimized()` и команду `cm::MINIMIZE`, которая переключает свёрнутое
состояние.

Ядро Turbo Vision включено в src/ этого крейта. Репозиторий собирается самостоятельно. Источник ядра — https://github.com/cat386/tvision-rs, лицензия MIT.


**Turbo Vision в графическом окне** — тот же API, что у [tvision-rs](../tvision-rs),
но программа рисуется не в терминале, а в собственном окне ОС.

* Windows, macOS, Linux/BSD (X11 и Wayland) — через [winit](https://crates.io/crates/winit);
* кадр выводится без GPU через [softbuffer](https://crates.io/crates/softbuffer),
  шрифты растеризуются [fontdue](https://crates.io/crates/fontdue);
* системный моноширинный шрифт (Consolas / Menlo / DejaVu Sans Mono ...) с
  запасными шрифтами для редких символов и иероглифов;
* рамки и блоки псевдографики (`─│┌╔═╬░▒▓█▀▄`) рисуются программно и стыкуются
  без щелей при любом размере шрифта;
* тёмная тема Gruvbox для графических элементов Material 3, мигающий курсор, мышь и колесо,
  изменение размера окна, HiDPI, полноэкранный режим, системный буфер обмена.

Вся логика интерфейса — представления, группы, окна, диалоги, меню, редактор,
файловые диалоги, справка — берётся из tvision-rs **без изменений**. gtvision
добавляет только новую реализацию трейта `platform::Backend`.

## Примеры

```
cargo run --example hello    # hello.cpp
cargo run --example tvedit   # многооконный редактор
cargo run --example tvdemo   # tvdemo: калькулятор, календарь, пятнашки, ASCII ...
cargo test                   # тесты псевдографики и отрисовки
```

Кроме того, в окне запускаются все примеры tvision-rs: `table`, `treeview`,
`three_panes`, `lfm`, `progress`, `colors`, `json_parse`, `json_table`,
`json_load`, `guide_contacts`, `demo` и уроки `learn_01_hello` …
`learn_08_todo`. Они сгенерированы из исходников tvision-rs; после обновления
tvision-rs пересоздайте их командой `cargo run --example sync_examples`.
Подробнее — [docs/10-examples.md](docs/10-examples.md).

## Перевод программы с терминала в окно

```toml
[dependencies]
gtvision = { path = "../GTVision" }
```

```rust
use gtvision::*;               // было: use tvision::*;

fn app_main() -> std::io::Result<()> {
    // было: Program::with_terminal(...)
    let mut app = Program::with_window(Some(menu()), Some(status()))?;
    app.run(&mut MyApp);
    Ok(())
}

fn main() -> std::io::Result<()> {
    run(GuiConfig::new("Моя программа").size(100, 30), app_main)
}
```

| tvision-rs (терминал)                 | gtvision (окно)                              |
|---------------------------------------|-------------------------------------------------|
| `use tvision::*;`                     | `use gtvision::*;` (реэкспорт всего tvision) |
| `Program::with_terminal(m, s)`        | `Program::with_window(m, s)`                    |
| `platform::default_backend()?`        | `GuiBackend::boxed()?`                          |
| `fn main() { ... }`                   | `fn main() { run(GuiConfig::new(..), app_main) }` |

Обёртка `run` нужна потому, что на macOS окно может работать только в главном
потоке, а `Program::run()` — блокирующий цикл. `run` запускает окно в главном
потоке, а программу — в отдельном. На Windows и Linux без `run` тоже работает:
`with_window` сам откроет окно в фоновом потоке.

Чтобы на Windows не открывалось окно консоли, добавьте в начало `main.rs`:

```rust
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]
```

## Настройки

```rust
GuiConfig::new("Заголовок")
    .size(80, 25)                 // начальный размер в символах
    .font_size(18.0)              // размер шрифта, логические пиксели
    .font("C:/Windows/Fonts/lucon.ttf")
    .palette(GRUVBOX_PALETTE)     // 16 цветов 0x00RRGGBB (по умолчанию; классика — VGA_PALETTE)
    .cursor_blink(true)
    .resizable(true)
    .fullscreen(false)
    .theme("Классическая")        // тема: Gruvbox, Классическая, Сумерки, ...
    .remember_settings(true)      // файл настроек рядом с программой (ИМЯ.conf)
```

**Файл настроек.** Тема, шрифт, размер шрифта, размер и положение окна
сохраняются при выходе в `ИМЯ.conf` рядом с программой (если там писать
нельзя — в `%APPDATA%\gtvision`) и читаются при запуске. Нет файла —
программа запускается с настройками по умолчанию из `GuiConfig`.

**Стандартный диалог настроек** — тема, шрифт и размер шрифта, с
предпросмотром на лету; выбор попадает в файл настроек:

```rust
if ev.command() == Some(CM_SETTINGS) {
    gtvision::settings_dialog(app);
    ev.clear();
}
```

Подробнее — [docs/11-settings.md](docs/11-settings.md).

Переменные окружения (важнее настроек в коде): `TVISION_GUI_FONT` — файл шрифта,
`TVISION_GUI_FONT_SIZE` — размер шрифта.

Заголовок окна во время работы: `gtvision::set_title("...")`.

## Клавиши окна

| Клавиша             | Действие                                        |
|---------------------|-------------------------------------------------|
| Alt+Enter           | полный экран / окно                             |
| Ctrl+= / Ctrl+-     | крупнее / мельче шрифт; окно масштабируется, число символов сохраняется |
| Ctrl+0              | исходный размер шрифта                          |
| крестик окна        | посылает программе `cm::QUIT`; если программа не отвечает — повторное нажатие закрывает принудительно |

Остальные клавиши переводятся так же, как в консоли Windows у tvision-rs:
Alt/Ctrl+буква — по физической клавише (Alt+X работает в русской раскладке),
на macOS Option и Cmd работают как Alt.

## Устройство

```
 главный поток (окно, winit)               поток программы (tvision)
 ───────────────────────────               ─────────────────────────
 клавиатура, мышь, размер   ── RawEvent ─▶  GuiBackend::read()
                                            Program::run() — как обычно
 Renderer → softbuffer      ◀── кадр ────   GuiBackend::flush(ScreenBuffer)
```

| Файл              | Что внутри                                                  |
|-------------------|-------------------------------------------------------------|
| `src/backend.rs`  | `GuiBackend` (трейт `Backend`), `run`, `ProgramExt::with_window` |
| `src/app_window.rs` | окно winit: события, мигание курсора, горячие клавиши       |
| `src/keys.rs`     | перевод клавиш winit в `KeyEvent` Turbo Vision              |
| `src/render.rs`   | ячейки → пиксели, перерисовка только изменившихся ячеек     |
| `src/font.rs`     | поиск системных шрифтов, метрики ячейки, растеризация       |
| `src/boxdraw.rs`  | программная отрисовка рамок и блоков                        |
| `src/config.rs`   | `GuiConfig`, палитры gruvbox и VGA                          |

## Ограничения

* `dos_shell` прячет окно и запускает оболочку в консоли, из которой запущена
  программа (в Windows без консоли система откроет новое окно консоли);
* метод ввода (IME) для иероглифов пока не подключён — ввод идёт по символам
  с клавиатуры;
* одна программа (`Program`) на один вызов `run`.
